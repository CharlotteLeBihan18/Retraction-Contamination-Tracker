# Index benchmark (PROFILE before and after)

Generated by `python -m scripts.benchmark_index` on a graph of 9354 papers.
Values used: DOI `10.1002/14651858.cd001724.pub2` (the most cited retracted paper), year 2023 (the most common year).
Time is the median of 50 runs after 3 warm-up runs, measured from Python, so it includes the network round trip. Database hits do not depend on the machine.

How to read the plan: `NodeIndexSeek` / `NodeUniqueIndexSeek` jump straight to the matching papers through the index; `NodeByLabelScan` reads every node of a label and `Filter` throws away the ones that do not match.

## paper_doi (unique constraint on Paper.doi)

| Query | Index | Plan (from the leaves up) | DB hits | Median time |
| --- | --- | --- | --- | --- |
| Find a paper by DOI | before (without) | NodeByLabelScan (p:Paper) → Filter → Projection → ProduceResults | 18,710 | 15.54 ms |
| Direct citers of a retracted paper (start of /contamination) | before (without) | NodeByLabelScan (r:Retracted) → Filter → Expand(All) → Filter → EagerAggregation → ProduceResults | 2,493 | 7.07 ms |
| Find a paper by DOI | after (with) | NodeUniqueIndexSeek (UNIQUE p:Paper(doi) WHERE doi = $doi) → Projection → ProduceResults | 3 | 3.54 ms |
| Direct citers of a retracted paper (start of /contamination) | after (with) | NodeUniqueIndexSeek (UNIQUE r:Paper(doi) WHERE doi = $doi) → Filter → Expand(All) → Filter → EagerAggregation → ProduceResults | 1,127 | 2.69 ms |

- Find a paper by DOI: **6,237x fewer database hits** with the index.
- Direct citers of a retracted paper (start of /contamination): **2x fewer database hits** with the index.
